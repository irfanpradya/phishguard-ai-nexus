## 🗺️ System Architecture

SentinelShield employs a modular design that separates concerns across three distinct layers:

### Frontend Experience (Next.js 14)
The control center provides an intuitive interface for monitoring ongoing campaigns, adjusting deception parameters, and reviewing intelligence reports. Real-time WebSocket connections ensure sub-second data updates, while the responsive design delivers a consistent experience across desktop, tablet, and mobile devices.

### Intelligence Core (FastAPI)
The backend orchestrates the entire simulation lifecycle, manages data persistence, and exposes RESTful APIs for external integrations. Each microservice handles a specific function—campaign management, data storage, analysis pipelines, and notification systems—allowing independent scaling and maintenance.

### Data Reservoir (PostgreSQL)
All captured intelligence is stored in a structured, queryable format. The schema supports complex analytical queries for pattern recognition, trend analysis, and correlation discovery. Automated backup routines ensure data integrity and availability.
